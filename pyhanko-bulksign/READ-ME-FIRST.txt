OnCourts Bulk Sign -- quick start
==================================

This folder is the whole app. Copy/extract it anywhere; nothing to install.
The HYP2003 DSC token library is already included.

  Windows:  OncourtsBulkSign.exe  + .env, court-seal.png, eps2003csp11v2.dll
  Linux:    OncourtsBulkSign      + .env, court-seal.png, libcastle_v2.so.1.0.0
  macOS:    OncourtsBulkSign.app  (settings, seal, token library and the token's
                                  driver installer are inside it)


SIGNING WITH YOUR DSC TOKEN
   a. Close Capricorn if it is running (both use port 1620; only one can run).
   b. Plug in the DSC token.
   c. Open the app. The grey box should show the certificate name.
      - "DSC token library not found": copy the token's PKCS#11 library into this
        folder (next to the exe), or install the token's driver. Then click Detect.
        The message lists every place the app looked.
   d. Type the token PIN -> START (status turns green).
   e. Bulk sign in the browser. Click STOP when finished.


Other token brands
   The app also finds the token library if the token's driver is installed, or
   if you copy the vendor's PKCS#11 library next to the app (64-bit; on Windows
   from C:\Windows\System32, NOT SysWOW64).


Windows notes
   - SmartScreen may warn about an unknown app: "More info" -> "Run anyway".
   - Allow the firewall prompt (the app only listens on this computer).

Linux notes
   - The first time you open the app, it asks to do a one-time setup and
     shows a password box: enter your computer login password. That is all.
     (It lets your user account access the token over USB.)
   - Make the app executable if needed: right-click -> Properties -> "Allow
     executing as program", or: chmod +x OncourtsBulkSign


macOS notes
   - The app is not yet signed by Apple, so the first time macOS blocks it
     ("can't be opened because Apple cannot check it for malicious software" or
     "Apple could not verify ..."). Allow it once:
       macOS 14 Sonoma and older:
         Right-click (or Control-click) OncourtsBulkSign.app -> Open -> Open.
       macOS 15 Sequoia and newer (or if there is no "Open" button above):
         1. Double-click the app, close the warning (OK / Done).
         2. System Settings -> Privacy & Security, scroll down, click
            "Open Anyway" next to OncourtsBulkSign, enter your Mac password.
         3. Open the app again -> "Open".
     After that it opens normally with a double-click.
   - Use the macOS-AppleSilicon zip on M1/M2/M3/M4 Macs and macOS-Intel on
     older Intel Macs (Apple menu -> About This Mac -> "Chip" or "Processor").
   - One-time driver install (the first time you open the app on a Mac):
       The app asks to install the DSC token's driver -> click Yes. The macOS
       Installer opens (the token vendor's own installer, included in the app):
       Continue -> Agree -> Install -> enter your Mac password -> Close.
       Then UNPLUG the token, plug it back in, and click Detect.
       If you clicked No, use the "Set up" button in the token box later.
       (The installer also adds the vendor's own token tool to Applications;
       this app does not need it, but it is part of the vendor's package.)


Reporting a problem: send a screenshot of the app window (including the
