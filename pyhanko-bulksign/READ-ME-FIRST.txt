OnCourts Bulk Sign -- quick start
==================================

This folder is the whole app. Copy/extract it anywhere; nothing to install.

  OncourtsBulkSign(.exe)   the app -- double-click it
  .env                     settings (no changes needed normally)
  court-seal.png           seal drawn in the signature box
  <token library>          your DSC token's .dll (Windows) / .so (Linux), if copied here


1. FIRST: CHECK THIS COMPUTER (takes ~10 seconds)
   Open the app -> click "Self-test".
   It signs a sample PDF and looks for your DSC token. The result is shown in the
   Activity box and saved to selftest-result.txt in this folder.
   RESULT: PASS  = the app works on this computer.


2. TEST MODE (no DSC token)
   Choose "Test mode" -> START. Bulk sign in the browser as usual.
   The PDF is signed with a test certificate ("untrusted" in Adobe -- expected).


3. REAL SIGNING WITH A DSC TOKEN
   a. Close Capricorn if it is running (both use port 1620; only one can run).
   b. Plug in the DSC token.
   c. Choose "DSC token". The grey box should show the certificate name.
      - "DSC token library not found": copy the token's PKCS#11 library into this
        folder (next to the exe), or install the token's driver. Then click Detect.
        The message lists every place the app looked.
   d. Type the token PIN -> START (status turns green).
   e. Bulk sign in the browser. Click STOP when finished.


Where the token library comes from
   Windows: usually nothing to copy. Installing the token's driver puts the
   library in C:\Windows\System32 and the app finds it there:
     HYP2003 India driver (from your CA)  -> eps2003csp11v2.dll
     HYP2003 HyperPKI driver (hypersecu)  -> HyperPKICsp11_2003.dll
     ePass2003 driver                     -> eps2003csp11v2.dll
   To avoid installing the driver, copy that 64-bit .dll from a PC that has it
   (C:\Windows\System32, NOT SysWOW64) into this folder, next to the exe.

   Linux: copy libcastle_v2.so.1.0.0 (inside the HYP2003 Linux x86_64 driver zip,
   folder "redist") into this folder, next to the app.


Windows notes
   - SmartScreen may warn about an unknown app: "More info" -> "Run anyway".
   - Allow the firewall prompt (the app only listens on this computer).

Linux notes
   - First time you choose "DSC token", the app asks to do a one-time setup and
     shows a password box: enter your computer login password. That is all.
     (It lets your user account access the token over USB.)
   - Make the app executable if needed: right-click -> Properties -> "Allow
     executing as program", or: chmod +x OncourtsBulkSign


Reporting a problem: send selftest-result.txt and a photo/screenshot of the error.
